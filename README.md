## How to run

1. Install Python 3 with numpy, pandas, matplotlib and Jupyter (`pip install numpy pandas matplotlib jupyter`).
2. Keep the `data/` folder next to the notebook and do not rename the files inside it.
3. Open `Assignment3\_Programming\_for\_AI.ipynb` in Jupyter.
4. Click **Kernel > Restart \& Run All**. The notebook runs from top to bottom.
5. The dashboard (`dashboard.png`, `dashboard.pdf`) and the animation (`wave.gif`) are saved in the `outputs/` folder.
